# 검증 기록 — 2026-10-23

## 수행한 확인

- Swift/XCTest 전체 자동 테스트 **33개 통과**: 매핑 보존/충돌/복원, 실제 hidutil 출력 파싱, 임시 폴더에서 설치/재설치/로그인 재적용/실패 복구.
- 설치 준비 단계 실패 후 외부 프로그램이 만든 F18을 복원 과정에서 삭제하는 오류를 재현하는 테스트 2개가 실패하는 것을 확인한 뒤 수정. OS 쓰기 시도 여부를 복원 기록과 별도로 보관하고, 쓰기 전 실패한 설치는 다음 시도에서 기준 상태를 새로 읽음.
- 실제 키보드 서비스 2개의 읽기 전용 진단. 기존 F18과 기존 게시글 자동 실행 감지. 이 도우미의 설치 기록과 등록된 로그인 작업은 없음.
- Apple Silicon/Intel 유니버설 빌드. 두 실행 파일의 두 아키텍처에서 LC_BUILD_VERSION minos 13.0 확인. Xcode 27 도구에서 Intel 관련 경고가 표시되었으나 실제 실행 파일 최소 버전은 13.0.
- AppKit 앱을 --demo로 실행하고 한국어 화면, 스크롤, 적용 버튼 알림, 입력란, 사용자 확인 상태를 UI에서 확인. 실제 키 설정은 변경하지 않음.
- plist 문법과 ad-hoc 코드 서명 검증. Developer ID 서명이나 Apple 공증은 수행하지 않음.

## 독립 코드 검토

별도 검토자가 파서, 명령 인자 구성, 잠금/복원, UI 상태 표현과 패키징을 확인했습니다. 준비 실패 후 소유권 오류와, 이미 F18이던 정상 설치의 기준 상태를 재설치 때 잃는 오류를 각각 재현 후 수정했습니다. 후자는 재연결 및 중간 재설치 실패를 포함한 실패 테스트 2개로 확인했고, baselineEstablished와 mappingAttempted를 분리한 뒤 전체 33개 테스트가 통과했습니다.

## 남은 수동 확인

실제 설치 및 복원, 로그아웃/로그인/재부팅, 다른 macOS 버전 및 Intel 실기기, 외장 키보드 재연결, 공증된 파일의 다른 Mac 최초 다운로드 실행은 미검증. README 체크리스트 참고.

현재 빌드는 로컬 테스트용이며 공개 배포 준비 완료를 의미하지 않습니다.
