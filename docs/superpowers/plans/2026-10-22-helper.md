# Hangeul Key Helper Implementation Plan

> Execution: implement in this session, then request an independent code review.

**Goal:** Ship a local macOS helper that makes the user's existing hidutil workflow accessible.
**Architecture:** Pure mapping policy and strict output parser; testable installation service; system backend; native AppKit UI and one-shot CLI; standalone app packaging.
**Tech Stack:** Swift 5 language mode, Swift Package Manager, Foundation, AppKit, XCTest. No external dependencies.
**Spec:** ../specs/2026-10-22-helper-design.md

## Global Constraints
macOS 13+, Korean UI, no host settings mutation during verification, no persistent event listener, preserve preexisting settings, manual F18 shortcut setup, no claims of notarization or zero latency.

## Review Focus
- Existing unrelated remaps must survive apply and restore.
- Mixed keyboard maps, malformed output and conflicting Caps bindings must fail closed.
- Failed registration or write must retain a usable recovery state.
- Existing F18 and legacy blog LaunchAgent must not be silently taken over.
- GUI must separate mapping success, login persistence and manual shortcut verification.

## Tasks
- [x] 1. Sources/KeyCore/Mapping.swift and HIDParser.swift; Tests/KeyCoreTests: test mapping preservation/conflicts/restore and real modern/legacy hidutil output before implementation.
- [x] 2. Sources/KeyCore/Installation.swift, SystemBackend.swift: test temp-directory backup, idempotent apply, login reapply, failures and restore using an injected system boundary; implement safe lifecycle and read-only status.
- [x] 3. Sources/HangeulKeyApp and Sources/KeyAgent: implement Korean UI with apply, keyboard settings, test, refresh, restore and actionable errors. Opening does not mutate settings; --demo for preview.
- [x] 4. scripts/build.sh, resources, README.md, docs: build universal .app/zip, optional Developer ID signing, test and validate app/plist, inspect live UI without changing key configuration.
- [x] 5. Independent review, resolve important findings, rerun suite, deliver artifacts and clearly identify remaining distribution credentials/manual checks.
