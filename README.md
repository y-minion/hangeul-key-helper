# 한영키 도우미 · hangeul-key-helper

**Caps Lock 한영 전환을 macOS 기본 기능으로 설정하는 작은 앱.**

터미널 명령을 복사하는 대신 버튼으로 Caps Lock → F18 매핑과 로그인 재적용을 설정합니다. 실제 입력 소스 전환은 macOS 기본 단축키가 담당합니다. 설정 후 앱을 닫아도 됩니다.

> **0.1.0 로컬 테스트 빌드.** macOS 13+를 대상으로 빌드한 Apple Silicon / Intel 유니버설 앱입니다. 현재 개발 머신에서 빌드·읽기 전용 진단·자동 테스트를 수행했으며, 모든 대상 OS/기기에서 검증된 정식 배포판은 아닙니다. 공개 배포 전 Developer ID 서명과 공증, 아래 수동 확인이 필요합니다.

## 사용 방법

1. 앱을 열고 **한영키 설정 적용**을 누릅니다. 기존 FOCD·Karabiner 등은 먼저 종료합니다.
2. **키보드 설정 열기**를 누릅니다.
3. **키보드 단축키 → 입력 소스 → 이전 입력 소스 선택**을 켜고, 단축키를 더블 클릭한 뒤 Caps Lock을 누릅니다. **F18**이 표시되어야 합니다.
4. 앱의 입력란과 평소 사용하는 앱에서 한글·영어를 번갈아 입력합니다.
5. 되돌릴 때는 앱의 **도우미 설정 복원**을 먼저 실행합니다. 수동으로 바꾼 입력 소스 단축키는 직접 되돌립니다.

자세한 사용법과 기존 블로그 설정 이전 방법은 [사용 안내](resources/사용안내.html)를 참고하세요. 기존 방법이 잘 동작하면 도우미로 옮길 필요가 없습니다.

## 하는 일

- `/usr/bin/hidutil property --matching keyboard`로 연결된 키보드 서비스의 매핑을 읽습니다.
- `0x700000039`(Caps Lock)를 `0x70000006d`(F18)로 재매핑합니다.
- 기존 다른 키 매핑을 보존하고, 최초 설치 전 상태를 저장합니다.
- 한 번 실행하고 종료하는 사용자 LaunchAgent로 로그인 시 재적용합니다.
- 복원 시 도우미 자동 실행을 해제하고 Caps Lock 변경만 되돌립니다.
- 기존에 이미 F18이었던 설정은 도우미 소유로 취급하지 않으며 복원 시에도 유지합니다.

입력 감시 앱, 키보드 확장, 외부 패키지, 관리자 권한, Apple Events 자동화를 사용하지 않습니다. 네트워크 요청·분석 수집·입력 기록이 없습니다.

## 제한 사항

- Caps Lock의 대문자 고정 기능은 없어집니다.
- F18 지정은 사용자가 시스템 설정에서 한 번 수행합니다. ‘키 매핑 적용’과 ‘입력 소스 전환 성공’은 별개로 표시됩니다.
- 키보드마다 매핑이 다르면 덮어쓰지 않고 중단합니다. v0.1은 키보드별 서로 다른 매핑을 합치는 기능이 없습니다.
- 로그인 후 연결/재연결한 키보드는 재적용이 필요할 수 있습니다. 상주 감시나 주기적 강제 재설정은 없습니다.
- 복원 시 설정했던 키보드를 연결하세요. 분리된 장치 상태를 즉시 되돌릴 수는 없습니다.
- `hidutil` 설정은 키보드 서비스 범위에 적용됩니다. 빠른 사용자 전환/여러 계정에서 서로 다른 설정은 별도 테스트가 필요합니다.
- 입력 소스가 세 개 이상이면 한글·영어 외의 언어로 이동할 수 있습니다.
- 기존 `com.user.capslock` 작업의 파일 또는 로드 상태가 발견되면 중복 자동 실행을 막기 위해 설치를 중단합니다. 기존 파일은 삭제하지 않습니다.
- 다른 앱이 동시에 매핑을 변경하는 상황은 완전하게 동기화할 수 없습니다. 기존 키 매핑 도구를 종료하고 사용하세요.
- macOS 업데이트 후 동작을 다시 확인하세요. 지연 0이나 모든 OS 버전에서의 호환성을 보장하지 않습니다.

## 개발 · 빌드

Xcode 또는 호환되는 Swift 개발 환경이 필요합니다. 앱 사용자는 개발 도구가 필요 없습니다.

```sh
swift test
./scripts/build.sh
```

결과:
- `dist/한영키 도우미.app`
- `dist/HangeulKeyHelper-0.1.0-macOS.zip`
- `dist/SHA256SUMS`

기본 빌드는 로컬 실행용 ad-hoc 서명입니다. **공증된 일반 사용자 배포판이라고 표시하지 마세요.**

```sh
# 읽기 전용 상태 확인: 키 설정이나 로그인 항목을 변경하지 않습니다.
.build/debug/key-agent --status

# 실제 설정을 바꾸지 않는 UI 미리보기
open "dist/한영키 도우미.app" --args --demo
```

`--reapply`는 설치된 기록의 enabled 상태가 true일 때만 키 설정을 바꾸는 로그인용 명령입니다.

## 저장 위치

| 용도 | 경로 |
|---|---|
| 복원 기록 | `~/Library/Application Support/HangeulKeyHelper/state.json` |
| 로그인 실행 파일 | `~/Library/Application Support/HangeulKeyHelper/key-agent` |
| 실행 로그 | 같은 폴더의 `login.log`, `login-error.log` |
| 자동 실행 등록 | `~/Library/LaunchAgents/app.hangeulkey.helper.plist` |

설정 작업은 공유 파일 잠금으로 직렬화합니다. 기록은 변경 전에 원자적으로 저장하며, 쓰기 후 실제 매핑을 다시 읽어 검증합니다. 복원 실패 시 기록을 남깁니다. 다른 프로그램이 Caps Lock을 바꿨으면 그 값을 덮어쓰지 않습니다.

## 수동 확인 체크리스트

자동 테스트는 임시 폴더와 가상 시스템 경계에서 수행합니다. 실제 키 입력과 macOS 로그인까지 대신 검증하지 않습니다.

- [ ] 깨끗한 계정에서 적용 → F18 지정 → 한영 전환
- [ ] 앱 종료 뒤에도 전환
- [ ] 로그아웃/로그인 및 재부팅 후 재적용
- [ ] 잠자기 복귀, USB/Bluetooth 키보드 재연결
- [ ] 기존 unrelated 매핑과 Caps Lock → F18 각각의 보존
- [ ] 복원 후 자동 실행 해제 및 재로그인 후 미적용
- [ ] 로그인 항목 거절/비활성화 시 실제 상태와 안내 확인
- [ ] macOS 13 이상 지원 대상 버전, Apple Silicon/Intel 실기기
- [ ] 서명·공증된 다운로드 파일을 다른 Mac에서 최초 실행
