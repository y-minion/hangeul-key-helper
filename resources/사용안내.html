한영키, 가볍게.

한영키 도우미는 macOS의 hidutil로 Caps Lock을 F18로 바꿉니다. 입력 소스 전환은 macOS가 담당합니다. 앱을 닫아도 적용된 매핑은 유지되며, 로그인할 때 짧게 실행되는 도우미가 재적용합니다.

처음 사용하기

  1. 기존 FOCD·Karabiner 등 키 매핑 앱을 종료하세요.
  2. 앱에서 한영키 설정 적용을 누르세요.
  3. 시스템 설정 → 키보드 → 키보드 단축키 → 입력 소스로 이동하세요.
  4. 이전 입력 소스 선택을 켜고 단축키를 더블 클릭한 다음 Caps Lock을 누르세요. F18이 표시되어야 합니다.
  5. 앱과 평소 사용하는 편집기에서 한글·영어를 번갈아 입력해 보세요.

F18이 표시되지 않으면 보조 키 설정에서 해당 키보드의 Caps Lock만 기본 기능으로 되돌리세요. 다른 보조 키까지 전체 초기화할 필요는 없습니다. F18을 쓰는 다른 단축키가 있으면 충돌을 해소하세요.

알아두세요

  • Caps Lock의 대문자 고정 기능은 사라집니다. 대문자는 Shift를 사용하세요.
  • 이전 입력 소스 단축키는 한영 전용이 아닙니다. 입력 소스가 세 개 이상이면 다른 언어로 이동할 수 있습니다.
  • 로그인 시 연결된 키보드에 적용합니다. 나중에 연결한 키보드는 앱에서 다시 적용해야 할 수 있습니다.
  • 키보드마다 서로 다른 매핑이 있으면 보존을 위해 변경을 중단합니다. 외장 키보드를 분리하고 다시 시도할 수 있습니다.
  • 로그인 항목 허용이 꺼져 있으면 자동 적용되지 않을 수 있습니다. 시스템 설정 → 일반 → 로그인 항목에서 확인하세요.
  • macOS 업데이트 후에는 직접 동작을 확인하세요. 모든 환경에서 지연 0을 보장하지 않습니다.
  • 설정은 현재 연결된 키보드 서비스에 영향을 주며 사용자 계정만의 영구 설정은 아닙니다. 빠른 사용자 전환 환경은 별도 확인이 필요합니다.

기존 게시글 방법을 이미 사용했다면

이미 잘 동작한다면 도우미로 바꿀 필요가 없습니다. 기존 com.user.capslock 자동 실행이 남아 있으면 중복 적용을 막기 위해 새 설치를 중단합니다. 기존 파일은 자동 삭제하지 않습니다.

도우미로 관리하고 싶다면 아래 명령을 본인의 터미널에서 실행해 기존 작업을 해제하고 파일을 보관하세요. 첫 명령에서 ‘서비스를 찾을 수 없음’이 나오면 이미 해제된 상태일 수 있습니다. 다른 오류라면 다음 단계로 진행하지 마세요.

launchctl bootout "gui/$(id -u)/com.user.capslock"

Finder의 이동 → 폴더로 이동에서 ~/Library/LaunchAgents를 열고 com.user.capslock.plist를 문서 폴더 등으로 옮겨 보관하세요. 그 다음 앱에서 상태를 새로 확인하고 적용하세요. 기존 F18 매핑은 그대로 보존합니다.

되돌리기 · 삭제하기

앱의 도우미 설정 복원을 먼저 누른 다음 앱을 삭제하세요. 도우미의 자동 실행과 실행 파일을 제거하고, Caps Lock 매핑만 설치 전 상태로 돌립니다. 이후에 추가한 다른 매핑은 보존합니다. 설치 전부터 F18이었다면 복원 후에도 F18입니다.

시스템 설정에서 수동으로 지정한 F18 단축키는 자동 복원하지 않습니다. 필요하면 직접 이전 단축키로 바꾸세요. 설정했던 외장 키보드를 연결하고 복원하세요. 연결이 끊긴 키보드의 상태를 즉시 복원할 수는 없습니다.

실패하면 복원 기록을 남깁니다. 상태를 확인하고 다시 복원하세요. ~/Library/Application Support/HangeulKeyHelper에 복원 기록과 로그인 오류 로그가 있습니다. 복원이 끝난 뒤에는 잠금 파일과 로그만 남을 수 있습니다.

개인정보와 배포 상태

입력을 수집하거나 전송하지 않습니다. 전역 입력 감시, Apple Events 자동화, 관리자 권한을 사용하지 않습니다. 테스트 입력은 앱을 닫으면 사라집니다.

이 로컬 빌드는 개발용 임시 서명이며 Apple 공증을 받지 않았습니다. 일반 공개 배포 전에는 개발자 서명·공증과 여러 기기에서의 수동 테스트가 필요합니다. Gatekeeper를 전체 해제하는 방법은 사용하지 마세요.
